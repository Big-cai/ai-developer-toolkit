# 调试提示词

## 上下文

- 现象：`{{symptom}}`
- 期望行为：`{{expected}}`
- 实际行为：`{{actual}}`
- 报错 / 日志：`{{logs}}`
- 近期改动：`{{changes}}`
- 相关代码：`{{code}}`

## 约束

- 没有证据不得断言根因。
- 按证据强度给假设排序。
- 优先选择最小的可复现解释。
- 不要做无关的重构。

## 指令

找出最可能的根因，并提出最小修复方案。

## 结果

返回：

1. 观察到的事实
2. 假设列表
3. 支持 / 反对每个假设的证据
4. 根因
5. 最小修复
6. 回归测试
7. 验证步骤

## 验证

提出的修复必须能解释原始现象，并包含一个在修复前失败、修复后通过的测试。
