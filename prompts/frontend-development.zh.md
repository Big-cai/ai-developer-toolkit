# 前端开发提示词

## 上下文

- 需求：`{{requirement}}`
- 项目技术栈：`{{stack}}`
- 项目规则：`{{rules}}`
- 现有组件：`{{components}}`
- 相关文件：`{{files}}`

## 约束

- 复用现有组件与工具函数。
- 没有充分理由不得引入新依赖。
- 保持现有 API 契约不变。
- 在对外边界上保持 TypeScript 类型显式。
- 不要重写无关文件。

## 指令

实现所要求的前端改动。

## 结果

返回：

1. 实施方案
2. 需要修改的文件
3. 代码改动
4. 测试
5. 验证命令
6. 风险 / 后续待办

## 验证

运行或推演以下检查：

- TypeScript 正确性
- lint
- 加载中 / 空 / 错误状态
- 相关场景下的响应式表现
- 可访问性
- 测试覆盖率
- 构建兼容性
