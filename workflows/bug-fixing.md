# Workflow: Bug Fixing

```text
Bug Report
 ↓
Reproduce
 ↓
Debugging Skill
 ↓
Root Cause
 ↓
Minimal Fix
 ↓
Regression Test
 ↓
Reviewer
 ↓
Human Review
```

The workflow prioritizes evidence over speculation.

A fix without a regression test is considered incomplete unless the project has a documented reason not to add one.
