# 技能：代码评审

## 目的

在变更集中发现正确性、安全、性能与可维护性方面的问题。

## 触发条件

在合并之前，或在 AI 生成实现之后使用。

## 输入

- git diff
- 需求
- 项目规则
- 相关架构上下文

## 工作流

```text
阅读需求
 ↓
阅读 diff
 ↓
追踪受影响的行为
 ↓
检查正确性
 ↓
检查安全性
 ↓
检查性能
 ↓
检查测试
 ↓
产出有证据支撑的发现
```

## 规则

- 先看被改动的行为
- 必须有证据
- 不重复上报
- 区分缺陷与建议
- 不要臆造运行时事实

## 输出

结构化的评审发现，包含严重级别、证据与修改建议。

## 验证

每一条发现都必须能追溯到代码或一条明确的项目规则。
