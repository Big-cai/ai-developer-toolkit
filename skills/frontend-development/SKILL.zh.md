# 技能：前端开发

## 目的

在既有代码库中实现前端功能，同时把不必要的改动降到最低。

## 触发条件

适用于 React / TypeScript 风格的功能实现、UI 行为变更、表单、表格、状态管理与 API 集成。

## 输入

- 已确认的需求
- 架构决策
- 项目规则
- 相关源文件
- API 契约

## 规则

- 复用现有组件
- 保持 API 契约不变
- 避免无关重构
- 为外部数据定义类型
- 处理加载中、空和错误状态
- 考虑可访问性

## 工作流

```text
需求
 ↓
检视现有代码
 ↓
制定计划
 ↓
实现最小改动
 ↓
新增 / 更新测试
 ↓
类型检查 + Lint + 构建
 ↓
自评审
```

## 输出

- 变更的文件
- 实现代码
- 测试
- 验证结果
- 剩余风险

## 验证

只有当验收标准与技术检查全部通过，功能才算完成。
