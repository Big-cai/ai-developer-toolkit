# 评估框架

## 为什么评估很重要

提示词的质量不能只看某一个例子跑得好不好。

本工具箱用可重复的标准来评估 AI 工作流。

## 评估维度

| 维度 | 要回答的问题 |
|---|---|
| 正确性 | 结果是否满足需求？ |
| 约束遵循 | 是否遵守了项目规则？ |
| 完整性 | 重要的情况是否都处理了？ |
| 一致性 | 面对相似输入时表现是否稳定？ |
| 可验证性 | 结果能否被独立检查？ |
| 效率 | 是否避免了不必要的上下文与工作量？ |

## 评估闭环

```text
基线
 ↓
运行 N 个代表性用例
 ↓
记录失败
 ↓
只改一个变量
 ↓
运行同一批用例
 ↓
对比
```

## 失败日志

使用模板：

```text

```

## 重要原则

不要为 token 数量或提示词长度做优化。要为实现任务的可靠性做优化。
