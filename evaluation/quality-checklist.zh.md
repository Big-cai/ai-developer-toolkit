# AI 输出质量检查清单

## 需求

- [ ] 每条需求都已处理。
- [ ] 假设已显式写出。
- [ ] 验收标准可测试。

## 代码

- [ ] 现有架构得到尊重。
- [ ] 类型正确。
- [ ] 没有不必要的依赖。
- [ ] 没有无关改动。

## 运行时

- [ ] 已考虑加载中状态。
- [ ] 已考虑空状态。
- [ ] 已考虑错误状态。
- [ ] 已考虑安全影响。
- [ ] 已考虑性能影响。

## 验证

- [ ] 已新增 / 更新测试。
- [ ] 类型检查通过。
- [ ] Lint 通过。
- [ ] 构建通过。
- [ ] 在需要处已完成人工复核。
